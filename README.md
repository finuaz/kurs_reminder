# kurs_reminder
---

## About
This mini project aims to remind user if exchange rate of certain rate from certain bank desirable.

## Author
- Iman Finuaz

## Architecture
- Scraper : Python + Requests + BeautifulSoup (bs4)
- Logic : Python + JSON/SQLite
- Notifier : 
  * Gmail SMTP (python smtplib)
  * Push Notification with ntfy.sh
- Scheduler : Github Action
